This release removes three sources of false positives. `taint` no longer reports `exec` called on a JavaScript or TypeScript regular expression, such as `/^a/.exec(path)`, as `taint.command_injection`. `behavioral` no longer reports `behavioral.contradicted_network` for a description that mentions the model once lacking a capability before granting it: "you did not have internet access ... this tool now grants you internet access". And a project's own function named `tool`, such as a test helper, no longer counts as an MCP tool registration.

Expect fewer findings than on v1.1.0, and some scans that returned `PARTIAL` (exit code 3) to return `SAFE`. Each call to a project's own `tool` function used to appear as a separate tool whose handler could not be found, and every one of them left a coverage gap.
