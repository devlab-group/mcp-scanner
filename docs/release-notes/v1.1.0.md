This release fixes cases where a scan reported more coverage than it had: registrations and sinks hidden by comments or brackets, descriptions taken from a fallback the server never serves, symlinks to source skipped without a gap, and matches that tree-sitter silently dropped in deeply nested files. It also removes SSRF false positives on servers that only call fixed APIs, and moves to Go 1.26.11 for GO-2026-6859 and GO-2026-6809. Upgrading is recommended.

Expect some scans that were `SAFE` on v1.0.0 to return `PARTIAL` (exit code 3). In each case the scanner is now reporting a gap it used to miss: an unresolved tool description, a refused symlink that can lead to source, or a file past the per-file time, text or depth limit. `verdict_reasons` and `limits_hit` in the report name the cause.

`go install github.com/devlab-group/mcp-scanner/cmd/mcp-scanner@v1.1.0` now works; v1.0.0 declared a different module path.
